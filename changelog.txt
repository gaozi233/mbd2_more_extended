MBD2 More Extended 1.1.0
=======================

Recipe conditions
- Every recipe condition now has a `showInGui` flag (default true):
  it controls whether the condition appears in the recipe GUI condition description, is editable in the condition
  editor, and is serialized to JSON/network/NBT. KubeJS can use `condition.showInGui(false)` or the chained
  `MBDRecipeJS.showInGui(false)` after a condition helper.
- The built-in `block` condition now supports block tags through a Mixin:
  adds a `tags` field, tag editor filter, tag-aware matching, JSON/network/NBT serialization and tooltips.
  KubeJS adds `blocksInStructureAny(minCount, maxCount, entries...)`, which accepts block IDs and `#tag` strings.
- Recipe UI condition slots: an item slot whose id is `@block_condition_<index>` displays the blocks/tags of that
  condition in a cycle, with the condition tooltip and without becoming a recipe input.

Editor
- The editor file/project list now has a visible scrollbar with mouse-wheel and drag support.
- The machine recipe type selector now supports text filtering by recipe type id.
- Added the client command `/mbd2_more_extended config`, which opens a client-only settings dialog with independent
  toggles for the editor enhancements and a separate global master switch. Disabling the master switch greys out the
  individual toggles but keeps their saved values.

Traits
- Added the `overstack_item_slot` machine trait. It supports two overstack modes:
  - EXACT: the configured value is the slot limit for 64-stack items; other items use floor(x * value / 64).
  - MULTIPLIER: each item's limit is floor(x * value).
  The overstack value can be configured above 64 in the editor. `allowOverstack` can disable the behavior entirely.

MBD2 More Extended 1.0.0
=======================

- Removed the optional JEI dependency declaration. The recipe viewer integration comes from
  MBD2/LDLib, so the mod does not reject older JEI versions (e.g. 15.20.0.133).

Recipe conditions
- Added the `nbt_compare` recipe condition for MBD2:
  reads a top-level key from the machine's custom data and compares its numeric value.
  Supports >=, >, <=, <, ==, !=, JSON/network/NBT serialization and the KubeJS `nbtCompare(...)` binding.

Ars Nouveau integration (optional)
- Added the `ars_source_storage` machine trait:
  - Ars I/O mode IN / OUT / BOTH (no per-face configuration)
  - recipe handler direction IN / OUT / BOTH, slot names and distinct flag
  - source storage persisted and synced, with an Ars manabar UI
  - Ars SourceManager provider: sourcelinks fill it, rituals can drain it, OUT pushes to nearby targets
- Added the `ars_source` recipe capability (integer):
  - recipe inputs consume source, outputs produce source
  - IN / OUT / BOTH are supported via separate recipe handlers
  - recipe preview and JEI/EMI ingredient use the plain purple mana texture

Development
- Ars Nouveau, GeckoLib and Curios are runtime-only dependencies for `runClient`.
- China-friendly Maven mirrors and ForgeGradle network workarounds.
- README documents setup, usage and known limitations.

Requirements
- Minecraft 1.20.1, Forge 47.4.10
- Multiblocked2 1.0.37+ (required)
- Ars Nouveau 4.12+ (optional, for the source integration)
- KubeJS 2001.6.5+ (optional, for the `nbtCompare` binding)
