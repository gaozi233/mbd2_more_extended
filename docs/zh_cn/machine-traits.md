# 机器特质

本模组新增以下机器特质：

- `ars_source_storage`：魔源存储
- `overstack_item_slot`：过载物品槽

## `ars_source_storage`

需要安装 Ars Nouveau。

在机器编辑器中添加：

```text
新生魔艺 - 魔源存储
```

### 可配置项

| 配置 | 说明 |
|---|---|
| 魔源容量 | 机器最多存储的魔源数量 |
| 传输速率 | 单次传输的最大魔源数量 |
| Ars 交互方向 | `IN` / `OUT` / `BOTH` |
| 配方处理器方向 | `IN` / `OUT` / `BOTH` |
| 槽位名 | 对应配方内容的 `slotName` |
| 是否唯一 | 对应 MBD2 的 `distinct` 语义 |

### Ars 交互方向

- `IN`
  - 魔源链接可以推入
  - 仪式不能抽取
- `OUT`
  - 仪式可以抽取
  - 每 10 tick 向 5 格内可接收目标推送
- `BOTH`
  - 类似魔源罐
  - 可接收，也可被抽取
  - 不主动推送

### 持久化与 UI

- 魔源数量会保存到存档并同步客户端
- 提供魔源条 UI
- 注册 `SourceManager` provider，机器加载/卸载时自动注册和注销

## `overstack_item_slot`

允许普通可堆叠物品超过原版 64 上限。

它不是替换原版 `item_slot`，而是一个独立特质。需要超堆时，在机器编辑器中添加：

```text
过载物品槽
```

### 继承配置

- 槽位数量
- 槽位上限
- 物品过滤器
- 自动输入/输出
- 物品渲染设置

### 专属配置

#### 允许突破堆叠上限

```text
allowOverstack
```

默认开启。

关闭后行为等同于普通物品槽。

#### 过载数值

```text
slotLimit
```

编辑器允许设置为 **1 ~ Integer.MAX_VALUE**，不受原版 64 限制。

#### 过载模式

```text
EXACT
MULTIPLIER
```

### EXACT：精确模式

设过载数值为 `n`，物品原本最大堆叠为 `x`：

```text
上限 = floor(x * n / 64)
```

因此：

```text
普通 64 堆叠物品 -> n
16 堆叠物品     -> floor(16 * n / 64)
1 堆叠物品      -> floor(1 * n / 64)
```

例如 `n = 1000`：

```text
64 堆叠物品 -> 1000
16 堆叠物品 -> 250
1 堆叠物品  -> 15
```

### MULTIPLIER：倍数模式

设过载数值为 `n`：

```text
上限 = floor(x * n)
```

例如 `n = 2`：

```text
64 堆叠物品 -> 128
16 堆叠物品 -> 32
1 堆叠物品  -> 2
```

### 输入方式

以下方式都使用同一套过载上限：

- 物流输入（漏斗、管道等 `insertItem`）
- GUI 鼠标点击
- Shift 快速移动

### 数量超过 127

原版 `ItemStack` 的 NBT `Count` 和网络编码使用 byte，超过 127 会变成负数。

本模组做了额外处理：

- 网络同步支持超过 127
- 机器存储 NBT 使用额外字段保存真实数量
- 退出世界再进入不会丢失

### 注意

- 其他模组的管道、箱子通常仍按自己的槽位上限拆堆。
- 过载槽中的大堆叠输出到外部容器时，可能需要拆成多个普通堆叠。
- 所有可堆叠物品都按所选公式缩放；工具、药水等低堆叠物品也会得到一个较小的上限。
