# 1.1.0

- 原版 `block` 条件支持方块标签
- 新增配方 UI 条件槽位
- 所有配方条件支持 `showInGui`
- 新增 KubeJS `blocksInStructureAny`
- 新增 KubeJS `MBD2Helper` 机器朝向、坐标与查询辅助
- 新增 KubeJS `MBD2RecipeHelper` 配方只读查询辅助
- 编辑器文件列表新增滚动条，支持拖动和滚轮
- 配方类型选择新增输入搜索
- 新增客户端指令 `/mbd2_more_extended config`，可分别开关编辑器增强，并提供独立的全局总开关
- 新增 `overstack_item_slot` 过载物品槽特质，可让普通可堆叠物品超过 64 上限
- 修复 MBD2 配方 GUI 槽位物品提示
